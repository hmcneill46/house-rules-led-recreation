What this model checks
  • The module has five anode pins 1, 3, 10, 7, 8 and seven cathode pins 12, 11, 2, 9, 4, 5, 6. Register values are decoded through those independent physical diode paths.
  • Four drivers serve 2 + 2 + 2 + 1 modules. Paired modules share anode switches and retain separate row sinks. Every physical pixel must have a unique driver/register address.
  • Current calculation uses 47 kΩ ISET, GCC = 64, scaling = 255, five scan slots and the datasheet's 32 kHz blanking timing. Full PWM is 255/256.
  • The supply selector represents explicit permission established by firmware, not current magically available when a cable is plugged in. During actual startup/detection the drivers stay shut down; afterwards an unqualified default-current source uses GCC8 dim mode. Full current needs configuration, a positive Type-C advertisement or completed BC1.2 CDP/DCP detection. A host suspend blanks the LEDs. MCU suspend current and analogue charger detection are outside this viewer.
  • The actual circuit still needs measurement and a full-size footprint check. A digital emulator cannot validate an incorrectly identified bottom-view pin-1 corner.
Offline model. No network requests. Artwork comes from this project's font and sequence; flash durations use nominal 60 fps. Model scope and checks.
