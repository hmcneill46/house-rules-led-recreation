# Bundled display models

The `.step` files are copied unchanged from the KiCad 10.0.7 library installed for this project. Their original internal attribution is retained. The source collection is the [KiCad Packages3D library](https://gitlab.com/kicad/libraries/kicad-packages3D); see [its bundled licence](KICAD-LIBRARIES-LICENSE.md) and [KiCad's library licence explanation](https://www.kicad.org/libraries/license/). The copied standard footprint library data in the neighbouring `footprints/` directory comes from the same KiCad distribution under the KiCad library terms.

`LMD07057AUE-101B.wrl` is the project's simplified display model from A1. `TI_RSE0010A-envelope.wrl` is a project-created, simplified maximum 1.5 × 2.0 × 0.6 mm package envelope with ten terminals and no exposed pad, based on the TI BQ24392 mechanical drawing. It is a visual aid, not a detailed manufacturer solid model. Real component markings, fillets and moulded profiles differ.

The finalization report records hashes for models referenced by each footprint. The manufacturing review export also hashes the full asset inventory and checks that every actual PCB model path resolves within the exported source folder. These images show the design; they are not photographs of manufactured hardware.
