# In-stock LED driver alternatives — engineering review, 31 October 2026

**Two promising candidates retain the PCB geometry: TLC59281RGER is the cheapest nominal/least-change choice; TLC59283RGER plus 7.15 kΩ resistors offers a more balanced power/switching comparison.** Neither is approved for manufacture from this research alone. Canonical CAD, BOM, firmware and prior quote inputs remain unchanged.

A subsequent [matched-current59283 comparison](tlc59283-matched-current-followup.md) finds that59283 plus7.15k resistors has better power margin and retains grouped switching. It should also be priced before a final engineering choice;59281 is the least-change candidate, not automatically the closest-performance replacement. Parent live JLC search confirmed 61,580 of the 7.15 kΩ C25980 resistor, Extended, $0.0018 at1+; precharge shutdown/ghosting still needs real qualification.

## TLC59281 technical decision

Manufacturer facts: the [TI Rev.B datasheet](https://www.ti.com/lit/ds/symlink/tlc59281.pdf) pp.3–7,13–15 and package addendum specify3–5.5V supply,2–35mA regulated sinks,17V output working limit,0.7×VCC logic HIGH and RGE0024C4×4mm/2.1mm EP. All24 terminals and EP25 agree with B2. LAT is **rising-edge triggered** and then replaces the shift contents with reserved test data; every LAT pulse therefore needs fresh output data. LAT-to-next-clock guard is100ns. It has no precharge. Simultaneous output transitions replace the59282's grouped delay. Current-error maxima at the stated test condition are±3% channel and±6% device; respective typical values are±1%. Powered leakage is0.1µA maximum; the extracted PDF text incorrectly displays the µA unit as mA, so the rendered table was checked. Supply test maxima at3kIREF are18mA on and8mA blank. A VCC=0 leakage guarantee was not found.

Our calculations/inspection:

- Existing6.8kIREF produces nominal**7.4118mA**, versus7.4249mA with59282: **−0.177%**. The same470µs light time/500µs phase and400Hz frame can remain; no brightness cap, reduced resolution or fixed-font limitation is introduced.
- At5.5V, a4.7k gate pullup draws at most1.18mA. The7.41mA sink setting gives the same useful low-gate margin as the old design. Powered0.1µA leakage gives only0.47mV pullup drop. This retains the existing gate-drive engineering inference; TI does not separately qualify this output as a MOSFET gate driver.
- `HardwareIO::shiftAndLatch()` writes eight fresh bytes, then exactly one1µs LAT pulse while BLANK is HIGH. Wake and shutdown use that same method; BLANK changes do not pulse LAT. This suits the destructive edge latch. The1µs high period already exceeds the100ns next-clock guard.8MHz SPI sends64bits in8µs, leaving room inside30µs dead time. Actual physical waveforms still need measurement.
- A separate [standalone digital probe](protocol_latch_probe.py) flushed random post-LAT reserved contents with1,000 fresh four-device frames; all output words matched. A second LAT without fresh data and a partial63-clock clear have explicit corruption counterexamples. [Recorded result](protocol-latch-probe-result.json). This illustrative register model does not execute the firmware or model a real chip's analogue/timing behavior.
- Reusing the existing conservative supply-current method increases full-brightness planning current by about**11.15mA** and DIM current by**8.17mA**. Approximate whole-product subtotals become443mA/82mA instead of432mA/74mA, before unresolved tolerances and small loads. This does not prove USB limits. Both switched rails, QOD, reset-safe EN and the existing shutdown/wake sequence remain necessary.

The unchanged layout has ground planes and local bypassing, but simultaneous transitions make supply/ground bounce, false clocks and ghosting important first-board checks. Test current qualification, host suspend, all-on temperature, startup/shutdown and bank-to-bank brightness. A same-function and same-appearance product is plausible; guaranteed optical matching or powered acceptance cannot be established from datasheets alone. The wider worst-case device-current tolerance is a tradeoff, even though nominal/typical behavior is very close.

## TLC59283 fallback

The [TI Rev.C datasheet](https://www.ti.com/lit/ds/symlink/tlc59283.pdf) confirms the same RGE0024C pin/EP geometry, but BLANK enables precharge. At3.3V, the specified precharge level spans about1.3–2.5V. The powered10V leakage test supports the existing5V gate pullups; it does not establish powered-off reverse-current behavior.6.8k gives7.7809mA,4.795% above B2. Matching nominal current requires about7.126k; alternatively448.50µs light time preserves nominal average at the higher peak. Neither adjustment is applied here. Precharge, rail transients, LED reverse bias and temperature would need separate acceptance. The in-stock59281 avoids these additional questions and keeps the existing resistor value.
