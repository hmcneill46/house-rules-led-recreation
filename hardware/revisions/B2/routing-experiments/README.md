# Historical routing experiments — do not order

This directory preserves intermediate placements, incomplete route attempts, quotation snapshots and diagnostic scripts. Names such as `final-routed6` describe a routing handoff, not a released product. Intermediate DRC reports can contain errors and unconnected nets.

Use the canonical editable project in [`../kicad/`](../kicad/), its final verification reports, and the explicitly generated review package described in [`../README.md`](../README.md). Never upload a PCB or quote snapshot from this directory as an order file. The scripts here are exploratory tools, not the final manufacturing export workflow.
