# Verification and historical reports

Final verification files are identified by the B2 revision README and manufacturing manifest. The directory also retains earlier placement/routing reports and incomplete audit probes to explain the design history. An early report named `placement`, `pass1`, `INCOMPLETE` or `NOT-FOR-ORDER` is not evidence that the canonical finished board passed.

The owner LED diode-test record is an owner-reported physical observation. Firmware and connection-model results are software checks; powered-board current, USB behavior, temperature and factory CAM/placement approval remain separate checks.
