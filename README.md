# house-rules-led-recreation
Software attempt at recreating Rose Finn-Kelcey's House Rules

[Web App](https://hmcneill46.github.io/house-rules-led-recreation/)

The physical display project is documented in [hardware revision B2](hardware/revisions/B2/README.md), including editable KiCad files, firmware, printable case models, verification and prototype cost evidence. B2 uses the seven owned 5 × 7 LED modules on a hidden custom PCB, with ready-assembled controller and USB modules to reduce prototype cost.

The earlier hardware design is preserved at [hardware-a1-2026-10-29](https://github.com/hmcneill46/house-rules-led-recreation/tree/hardware-a1-2026-10-29). Read each revision's status and assembly guide before ordering or mixing files.
